## 2. Tools (in the KB, `working/tools/`)

- `tdn_strip.py SRC DST`: copies a PiSP tuning with each `rpi.denoise` `tdn` member cut out of the text (`diff` shows the
  `tdn` lines only; bytes read and written as they are, CRLF kept). Refuses: SRC not strict JSON or not `"target": "pisp"`;
  DST = SRC, inside a `defaults*` directory, not `.json`, or existing with other content; any difference other than the
  `tdn` paths. Writes via temp file + fsync + rename and reads back. Tested on cinemate's `imx585_mono.json` (measured).
- `be_overlap.py RAWDIR --prefix e3 [--take NAME[:LIB]]`: takes found from `<prefix>-<NAME>.out`; take length and delivered
  frames from the console; the frame period from the take's own SOF interval; each take aligned on the `clocks at
  record_start` pair. Section 4 adds the **largest queued share in a 20-s bin** (a take that tips late shows there: pv12-P1
  is 0.73 over the take, 0.87 in seconds 165-185) and the job count; section 6 adds **UI CPU per frame** (0 on evening-2
  data, whose logs hold no UI threads).
- `take3v3.sh`: the mode from `TAKE_CLEAR_HDR` / `TAKE_BITS` / `TAKE_FPS` / `TAKE_COMPRESSION` (defaults = the B1 rig), a
  `mode:` line with what Core reports (including `tuning_file`), `clocks at record_start: epoch= mono=`, the UI binary's
  threads in the 1 Hz log. It has no shebang: run it as `bash ~/apertar-kb/working/tools/drop-frames-2026-11-01/take3v3.sh`.
