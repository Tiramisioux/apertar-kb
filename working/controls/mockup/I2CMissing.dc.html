sudo cp /boot/firmware/config.txt /boot/firmware/config.txt.$(date +%Y%m%d-%H%M%S) sudo sed -i -E 's/^(dtoverlay=(vc4-kms-DPI-4inch|waveshare-4dpi|waveshare-touch-4dpi)([,[:space:]]|$))/#\1/' /boot/firmware/config.txt sudo reboot
Safe to run twice. It also comments the same lines under another filter, such as [pi4].
To undo: copy the backup back (sudo cp /boot/firmware/config.txt.20261028-211403 /boot/firmware/config.txt), or with a card reader remove the # on these lines in config.txt on the boot partition.
