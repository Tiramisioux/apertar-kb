## The ten decisions most likely to collide with a rework toward original Apertar

Ranked by how directly a "pull back to 1.6.0" plan would remove or change them, and by whether the feature changes a
STOCK camera (then the rule is: make it an operator option, do not remove it).

1. **DB-17 Lossless ISO cap 1600** (upstream 800) and **DB-21/DB-20** auto ISO in lossless and Auto on the ISO/WB
   dials: they change a stock camera's lossless behaviour. Keep, but behind an operator setting.
2. **DB-39 Red timecode default on** changes the stock HDMI monitor (upstream: never red there). Keep the switch;
   the stock default must equal 1.6.0 per screen.
3. **DB-52 fps ceiling from the sensor probe** (4K SDR 60; upstream table caps 30) plus **DB-35** no
   `[camera] max_fps`: a rework that restores the table removes his choice; a stock camera gets new rates.
4. **DB-45 An active ladder blocks manual resolution / bit depth / Clear HDR** (and **DB-53** the touch UI's changes
   are refused, not greyed): a rework moving the ladder or the command plane must keep the block, not return to DB-43.
5. **DB-13/DB-14 Clear HDR on = uncompressed, off = lossless, however switched**: couples compression to Clear HDR,
   so turning Clear HDR off changes the stock compression setting. Must stay his rule for Clear HDR and leave stock
   SDR compression untouched.
6. **DB-65 "Everything back"**: trim at mount default on, `DONTNEED=sync` default (upstream hard-codes the per-write
   call), preview TDN switch, RAM buffer, Log, clip names, Boot Config, Remote controls. Two defaults change a stock
   camera (trim on, `sync`): operator options, not removal.
7. **DB-37/DB-34 Value lists in `UI.conf` [General]**, one owner, Core reads and writes them, pots/encoders/buttons
   step through them, free stepping and flicker-free angles: a rework moving lists to `camera_settings.conf` or the UI
   would contradict an approved design.
8. **DB-18/DB-19 Clear HDR holds ISO/WB and refuses auto, ISO caps 1585/720**: a rework of the camera settings
   path can drop the hold or the refusal.
9. **DB-33/DB-41 Marking of camera-decided values** (italics; auto values white) and the resolution line
   "16-bit - Clear HDR" on all three screens: a UI rework toward the upstream look can remove them, while DB-58 also
   asks for "original UI look".
10. **DB-61/DB-62/DB-63/DB-64 Write-path and Log rules**: discard on record during a safety-stop flush; COMP1 kept
    for SDR, no Log in SDR lossless; Log one step down and in parallel with every compression. A storage or pre-roll
