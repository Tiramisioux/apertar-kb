### Core writer facts (first-hand, apertar-core@f60e301)

Rows are 7680 B (stride) so the 2200-row readout cropped to 2160 rows stays aligned.
- cDNG payload write (`CdngEncoder.cpp:1861-1912`): rows converted by writeDngRowBytes into a reusable scratch of max(rowBytes, clamp(64 rows, 256 KiB, 4 MiB)) and flushed with writeAll -> ~4 MiB write() calls (4 MiB = 1024 pages, aligned size; buffer itself is a std::vector, not 4096-aligned). MLV payload (`MlvEncoder.cpp:862-905`) same chunking via payloadScratch_. MLV VIDF header (:1020-1033) writes `frameSpace = 0`; the MLV format's frameSpace field is the designed place to pad frame data to an alignment.
